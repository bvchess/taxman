Chapter 5

The search

A search tries sets of promotions one candidate at a time, and a bound proves when no more searching is needed.

Once the frames are set, all that is left to choose is which candidates to promote. Before the frame solver searches, it asks whether an earlier game has seen this search scenario already. When game n poses the search problem of one of the games just before it, game n is a repeat (chapter 2), and that game's promotions are the same as game n's. That's what happens in game 39. The new number (39) lands in a closed frame, where descending greedy keeps 39 and drops 22, and the frames with freedoms and their candidates stay as they were in game 38. Because of that, using the same promotions game 38 chose guarantees an optimal set of promotions in game 39.

Game 45 isn't so lucky. The maximal factors of 45 are 15, in frame 1, and 9, which with 27 made a closed frame of its own in game 44. 45 joins the two frames into one, so frame 1 changes, and game 45 poses a novel search problem. It has 8 candidates, so 256 sets of them. Game 5,060 has 1,380 candidates, and far too many sets to try one by one.

Branch and bound

The state lemmaLemma R1proved, proof on GitHub

What a node can still promote depends only on the frames its promotions leave.

Precisely.P ∪ X is a promotion set exactly when each member of X is a factor of its home in state(P), and every frame of state(P) stays winnable with X applied.

A search tries the sets one candidate at a time. At each step it takes one candidate and splits the search tree: one branch promotes it, the other goes on without it. Each point where it splits is a node. All the while the search keeps the best game it has found, and each node has a bound: a limit on what the promotions of that branch could still add. A branch whose bound cannot beat the best game found is a dead end, so the search stops exploring that path. This way of searching is called branch and bound.

The figure's bound

The figure prunes with a simpler bound than the solver's: the sum of every candidate that could still be promoted alone with the node's promotions. In its search, candidates can be promoted together exactly when U* with them is playable (Theorem X7).

The whole search of game 45 takes 13 nodes, and its bound drops 6 branches without looking inside them. When no branch is left, no set of promotions can beat the best one found.

The bound

The figure's bound adds up every candidate that could still be promoted alone along with the promotions the branch has already selected. Every set that can be promoted passes this test, but so do many sets that cannot, so the bound is loose: at game 45's root the bound is 107, but eventually we learn the best set of promotions can only contribute 39.

The signed frame theoremTheorem B1proved, proof on GitHub

Promotions that can be made together pass the test in every frame.

Precisely.Give each move of a frame, and each number promoted into it, the vector of its maximal factors there, and each number promoted out of it its unit vector. A promotion set makes them linearly independent in every frame, over every field.

The frame solver's bound is a sharper test of the same kind: one that every set of legal promotions will pass, though some that cannot be made pass it too. It grows from the loop of chapter 1. List, for each number of a set, the maximal factors outside the set that could pay for it. If some of the numbers, taken together, list every factor an even number of times, the set cannot be played. The loop 10, 14, 15 and 21 lists each of 2, 3, 5 and 7 twice.

The frame boundCorollary B2proved, proof on GitHub

The heaviest set of candidates that passes the test in every frame bounds what a node can add.

Precisely.At a node with the promotions P and the candidates C, every completion P ∪ X has ΣX at most the heaviest ΣI, I ⊆ C independent in every frame together with P, within the node's promotion limit. The solver calls it the GF(2) bound. The only sets it lets through that cannot be promoted hold an odd core in some frame.

The test requires that no group of a set's numbers list every factor an even number of times. This is linear algebra over GF(2), the arithmetic of even and odd, so it is quick to check, and a classical algorithm finds the heaviest set that passes it. That set's sum bounds what a branch can still add. The solver applies the test to the promotions frame by frame, at every node.

Some sets pass the test and still cannot be played. The smallest board with one is game 45's: 12, 18, 20, 30 and 45. Sets like it are all that the bound misses.

Learning from dead ends

Conflicts and nogoods

A conflict is a minimal part of the heaviest set that cannot be promoted, a median of two members in games 760 to 1,000 (conflicts). Each is kept as a nogood, a set that cannot be promoted from the root (nogoods).

When the heaviest set that passes the test can be promoted, it is the best the branch can do, and the branch is done. When it cannot, the solver finds a few of its candidates that cannot be promoted together, often only one or two. Every better set leaves one of them out, so the node branches on them: promote one, or go on without it.

The solver remembers each dead end it finds. A set of candidates that cannot be promoted together from the root cannot be promoted anywhere in the tree, so once such a set is found, no other branch tries it again.

The prime-exchange theoremTheorem R2proved, proof on GitHub

Where two primes play the same part, a set of promotions and its mirror image can both be promoted or neither, and the heavier is known in advance.

Precisely.If exchanging the primes p < q maps the root onto itself, and no candidate is divisible by pq, p² or q², every heaviest promotion set has cp ≤ cq, where cr sums x/r over its multiples of r. At game 1,300, 41 and 43 are such a pair (prime exchanges).

Some pairs of primes play the same part in a game. In game 1,300, 41 and 43 are such a pair. Its candidates include 41 times 4, 6, 8, 9, 10, 12, 14 and 15, and 43 times the same eight numbers, and swapping 41 and 43 in every number leaves the frames, taken together, exactly as they were. So every set of promotions has a twin, made by the same swap, and the twin can be promoted exactly when the set can. A set that promotes 164 = 4 × 41 has a twin that promotes 172 = 4 × 43 in its place, 8 more. Each swap trades a multiple of 41 for the same multiple of 43, or back, so it is easy to tell which twin is heavier, and the search tries only the heavier one.

A head start

The two starts of game 5,060

As sums of promotions, the part of the score a search chooses: the best is 570,330, and the search starts at 570,285 from game 5,059’s optimal set and at 569,735 on its own. The frame solver measured both, each search stopped after its first thousand nodes (the start of game 5,060). What a start below the best costs a search was measured at game 3,020 (a start below opt(n)).

A search does not start from nothing. The search of game n starts from the optimal set of game n − 1, carried over to game n (chapter 2), and that start is usually optimal or close to it. Game 5,060’s search starts 45 points below the best score this way; from a start of its own, it would begin 595 below. A branch is dropped only when its bound cannot beat the best game found, so the nearer the search starts to the best, the more branches it can drop. A start far below the best can make a search many times longer.

The near-repeat lemmaLemma R7proved, proof on GitHub

A branch that poses part of an earlier game's problem adds no more than that game's best, so the search may drop it.

Precisely.Under three conditions against a game m, every completion of a node is a promotion set of m's root problem, worth at most a bound Z of its best.

Game n − 1 helps another way too. Where a branch of game n poses only part of the problem that game n − 1 posed, the search can drop it, by the near-repeat lemma. It is a repeat in part: game n − 1’s search has already shown how much that part can add.

What proves a game

The dual-bound lemmaLemma R4proved, proof on GitHub

A search that drops only branches that cannot do better ends with the best set of promotions.

Precisely.In an exact search, every promotion set heavier than the best found, and true to every mirror, lies in an open branch. So a search with no branch left proves P*, the heaviest promotion set's sum, equal to its best.

When all branches have been explored, the search has proved that no set of promotions beats its best one: every set was either tried or dropped by a bound that showed it could not do better. So its best game is the best of the frame model, which is an optimal game wherever statement U holds. This is how 1,612 games of the chain were proven.

A search can also stop early. No game of n scores more than the best score of game n − 1 plus n, the ceiling (chapter 2). A search whose best game reaches the ceiling has nothing left to find, so it can stop. That is how 494 searches of the chain ended, 490 of them at their start, before a branch was explored.

What it costs

The chart shows the nodes of every game of the chain that needed a search, 1,618 games. They climb from a single node in the small games to billions at the end: game 5,060 took 3.2 billion.

A subtree grows about 2.6 times for every 100 points of its gap.

What decides the cost is the gap at each node: how far its bound is above the best game found. A branch with a large gap cannot be dropped, and it splits again and again before its bound comes down. The parity bound

The parity boundTheorem W1proved, proof on GitHub

The heaviest set that passes the test bounds opt(n).

Precisely.A playable set is independent with its own coordinates over GF(2) (the independence lemma, P10), which is independence at both parities of the layer. So opt(n) is at most the heaviest set independent at both parities. Weighted matroid intersection finds it, and a weight split checks its value.

The test needs no frames. Applied to the whole board, it bounds opt(n) itself. List, for each number of a set, its maximal factors outside the set. In a set that can be played, no group of numbers lists every factor an even number of times. So the heaviest set with no such group bounds opt(n). We call it the parity bound. At the root of a search, the frame solver's bound with the weight of U* added comes to the same number on every board from 2 to 8,191. The parity bound is the bound of the prover, the second program of chapter 6.

The two gapsmeasured, evidence on GitHub

The parity bound's gap above opt(n) is about a tenth of Franklín and Moniot's.

Precisely.130 points against 1,200 in games 1,000 to 1,300. Theirs is the heaviest set with a payment scheme, a maximum-weight matching (what the paper proves).

Franklín and Moniot's paper gives a looser bound: the heaviest set whose numbers can each be given a maximal factor of their own, from outside the set, to pay with. Every set that passes the parity test passes theirs, and the parity bound comes far closer to opt(n): its gap is about a tenth of theirs.

Why one is stricter than the other shows in a count. A payment scheme gives each number of a set a maximal factor of its own, from outside the set, to pay with. Count the schemes that pay with the same factors. A set is allowed by Franklín and Moniot's bound when some choice of factors gets at least one scheme, and by the parity bound when some choice gets an odd number. It can be played exactly when some choice gets exactly one.

The counting theoremTheorem C2proved, proof on GitHub

A set has a payment scheme, passes the parity test, or can be played exactly when some set of factors gets at least one, an odd number, or exactly one of its schemes.

Precisely.With per(S, T) the number of schemes of S onto the factors T, the three conditions are per(S, T) ≥ 1, odd, or 1, for some T. The odd count is independence over GF(2), since a permanent is its determinant mod 2.

Two schemes on the same factors differ around a loop: the triangle's second scheme is its first turned once around. Whichever of 6, 10 and 15 is played first takes both of its primes as tax, and one of the other two is left with nothing to pay with. Swap 6 for 9 and the loop opens: one scheme, and the set plays, 9 first.

The first odd coreProposition C3proved, proof on GitHub

Below game 45 every set that passes the parity test can be played.

Precisely.Every S ⊆ {2, …, 44} independent with its own coordinates over GF(2) is playable, so the parity bound is opt(n) for n ≤ 44, and {12, 18, 20, 30, 45} is an odd core.

An odd count is what the parity test cannot tell from one. The five numbers 12, 18, 20, 30 and 45 have three schemes, all paying with 4, 6, 9, 10 and 15. Three is odd, so they pass the test, yet they cannot all be played: every number has two or more factors to pay with and every factor two or more takers, so peel has no safe step. A set like this, which passes the test and cannot be played, is an odd core, and game 45 is the first with one.

Exact to game 77measured, evidence on GitHub

The parity bound equals opt(n) for every game up to 77, and exceeds it at game 78.

Precisely.The prover's run on games 2 to 2,530 records each bound, checked by its weight split: at game 78 it is 1,992 against opt(78) = 1,991 (the evidence). U* with 28, 30, 36 and 39 passes the test at that weight; the nine numbers drawn are what peel leaves of it.

Up to game 77 the parity bound is exactly opt(n): below game 45 no board has an odd core, and from game 45 to game 77 none of them raises the bound. At game 78 the bound first misses, by one point: 1,992 against opt(78) = 1,991. A set worth 1,992 that passes the test is the optimal set of game 78 with 28 promoted in place of 27, and these nine of its numbers cannot all be played.

Each of the nine numbers lists two or three of the nine factors, and every factor is listed twice or more, so peel has no safe step. Yet no group of the nine lists every factor an even number of times. It is an odd core, the first that raises the bound.
