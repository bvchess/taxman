Chapter 5

The search

A search tries sets of promotions a candidate at a time, and a bound proves when nothing better is left.

Once the frames are set, all that is left to choose is which candidates to promote. Game 45 has 8 candidates, so 256 sets of them, and only some can be promoted together. Game 5,060 has 1,380 candidates, and far too many sets to try one by one.

The state lemmaLemma R1proved, proof on GitHub

What a node can still promote depends only on the frames its promotions leave.

Precisely.P ∪ X is a promotion set exactly when each member of X is a factor of its home in state(P), and every frame of state(P) stays winnable with X applied.

A search tries them a candidate at a time. At each step it takes one candidate and splits in two: one branch promotes it, the other goes on without it. Each point where it splits is a node. All the while the search keeps the best game it has found, and at each node a bound: a limit on what the promotions of that branch could still add. A branch whose bound cannot beat the best game found is dropped, unexplored. This way of searching is called branch and bound.

The figure's bound

The figure prunes with a simpler bound than the solver's: the sum of every candidate that could still be promoted alone with the node's promotions. The page runs the search with web/js/model.js, where candidates can be promoted together exactly when U* with them is playable (Theorem X7).

The whole search of game 45 takes 13 nodes, and its bound drops 6 branches without looking inside them. When no branch is left, no set of promotions can beat the best one found.

The bound

The figure's bound adds up every candidate that could still be promoted alone with the branch's promotions. Every set that can be promoted passes that test, but so do many sets that cannot, so the bound is loose: at game 45's root it is 107, while the best game adds 39.

The signed frame theoremTheorem B1proved, proof on GitHub

Promotions that can be made together pass the test in every frame.

Precisely.Give each move of a frame, and each number promoted into it, the vector of its maximal factors there, and each number promoted out of it its unit vector. A promotion set makes them linearly independent in every frame, over every field.

The frame solver's bound is a sharper test of the same kind: one that every set of promotions that can be made passes, though some that cannot be made pass it too. It grows from the loop of chapter 1. List, for each number of a set, the maximal factors outside the set that could pay for it. If some of the numbers, taken together, list every factor an even number of times, the set cannot be played. The loop 10, 14, 15 and 21 lists each of 2, 3, 5 and 7 twice.

The frame boundCorollary B2proved, proof on GitHub

The heaviest set of candidates that passes the test in every frame bounds what a node can add.

Precisely.At a node with the promotions P and the candidates C, every completion P ∪ X has ΣX at most the heaviest ΣI, I ⊆ C independent in every frame together with P, within the node's promotion limit. The solver calls it the GF(2) bound. The only sets it lets through that cannot be promoted hold an odd core in some frame.

The test asks that no group of a set's numbers list every factor an even number of times. It is linear algebra over GF(2), the arithmetic of even and odd, so it is quick to check, and a classical algorithm finds the heaviest set that passes it. That set's sum bounds what a branch can still add. The solver applies the test to the promotions frame by frame, at every node.

Some sets pass the test and still cannot be played. The smallest board with one is 45's: 12, 18, 20, 30 and 45. Sets like it are all that the bound misses.

Learning from dead ends

Conflicts and nogoods

A conflict is a minimal part of the heaviest set that cannot be promoted, a median of two members at n = 760 to 1000 (conflicts). Each is kept as a nogood, a set that cannot be promoted from the root (nogoods).

When the heaviest set that passes the test can be promoted, it is the best the branch can do, and the branch is done. When it cannot, the solver finds a few of its candidates that cannot be promoted together, often only one or two. Every better set leaves one of them out, so the node branches on them: promote one, or go on without it.

The solver remembers each dead end it finds. A set of candidates that cannot be promoted from the root cannot be promoted anywhere in the tree, so once one is found, no other branch tries it again.

The prime-exchange theoremTheorem R2proved, proof on GitHub

Where two primes play the same part, a set of promotions and its mirror image can both be promoted or neither, and the heavier is known in advance.

Precisely.If exchanging the primes p < q maps the root onto itself, and no candidate is divisible by pq, p² or q², every heaviest promotion set has cp ≤ cq, where cr sums x/r over its multiples of r. At 1300, 41 and 43 are such a pair (prime exchanges).

Some pairs of primes play the same part in a game: exchanging the two in every number maps the frames onto themselves. Then every set of promotions has a mirror image, which can be promoted exactly when it can, and which of the two is heavier is easy to tell. So the search tries only the heavier side of each mirror.

What proves a game

The dual-bound lemmaLemma R4proved, proof on GitHub

A search that drops only branches that cannot do better ends with the best set of promotions.

Precisely.In an exact search, every promotion set heavier than the best found, and true to every mirror, lies in an open branch. So a search with no branch left proves P*, the heaviest promotion set's sum, equal to its best.

The near-repeat lemmaLemma R7proved, proof on GitHub

A branch that poses part of an earlier game's problem adds no more than that game's best, so the search may drop it.

Precisely.Under three conditions against a game m, every completion of a node is a promotion set of m's root problem, worth at most a bound Z of its best.

When no branch is left, the search has proved that no set of promotions beats its best one: every set was either tried or dropped by a bound that showed it could not do better. So its best game is the best of the frame model, which is an optimal game wherever statement U holds. That is the proof of 1,612 games of the chain.

A search can also stop early. No game of n scores more than the best score of game n − 1 plus n, the ceiling. A search whose best game reaches the ceiling has nothing left to find, and it stops there.

What it costs

The chart shows the nodes of every game of the chain that needed a search, 1,618 games. They climb from a single node in the small games to billions at the end: game 5,060 took 3.2 billion.

How a subtree growsmeasured, evidence on GitHub

A subtree grows about 2.6 times for every 100 points of its gap.

Precisely.In the profile of game 4949, a subtree's steps rose 0.42 decades per 100 points of its gap, with a rank correlation of 0.88 to 0.96. Game 4950's nodes sit 200 to 230 points higher, and its subtrees are 5 to 8 times larger (the hard games).

What decides the cost is the gap at each node: how far its bound is above the best game found. A branch with a large gap cannot be dropped, and it splits again and again before its bound comes down. In game 4949, near the end of the chain, a subtree grew about 2.6 times for every 100 points of its gap.
