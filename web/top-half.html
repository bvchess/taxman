Chapter 3

The top half

The numbers above n/2 carry most of the score: about 93% of it in the games that need a search. One greedy pass chooses them.

Sources

Where n fits or is a prime, game n − 1 settles game n at once (chapter 2). Game 21 is neither: 21 does not fit into game 20's optimal set, and 21 = 3 · 7.

Layers, precisely

The layer of x is Ω(x), its prime factors counted with multiplicity: Ω(12) = Ω(2 · 2 · 3) = 3, and Ω(1) = 0. A maximal factor x/p has the layer Ω(x) − 1, so every line of the maximal-factor graph joins two neighboring layers.

Start from the pot of game 21, and set its numbers out as chapter 1's graph does, in columns by layer. A number's layer is its count of prime factors, with repeats: 12 = 2 · 2 · 3 is in layer 3, every prime is in layer 1, and 1 alone is in layer 0. A number's maximal factors lie one layer down, so every line runs one column to the right.

Sources, precisely

The sources of game n are the s with n/2 < s ≤ n. Since 2s > n, no multiple of s but s itself is on the board, so no move takes s as tax. The factors are 1 to ⌊n/2⌋.

Now cut every column at n/2. A number above n/2 divides no other number on the board, since twice it is already more than n. So no move takes it as tax: the player plays it as a move, or the taxman takes it at the end. We call the numbers above n/2 the sources, and the numbers up to n/2 the factors. In game 21 the sources are 11 to 21, below the line.

The top half's sharemeasured, evidence on GitHub

Precisely.Over the 1,618 games whose recorded search explored nodes, ΣU* / score runs from 91.9% to 97.1%, and from 92.1% to 93.2% past game 500. The recorded game plays exactly U* above n/2, so ΣU* is what its sources score.

The sources are the larger half of the numbers, so they are where most of the points are. In the games of the chain that needed a search, the sources the optimal game plays carry about 93% of its score.

Descending greedy

Which sources should a game play? It cannot always play them all. In game 21 the primes 11, 13, 17 and 19 each have one maximal factor, 1, and two moves cannot share a payment, so the player can play at most one of the four.

Descending greedy, precisely

It takes the sources in decreasing order and keeps each one that, with the sources kept so far, is playable, which peel decides (the theory). The frame solver runs it as part of its setup (setup in the code).

Descending greedy chooses the sources in one pass. It takes them from the largest down and keeps each one that is still playable together with those it kept before. In game 21 it keeps 21, 20, 19 and 18, then rejects 17, since 1 already pays for 19. It keeps 16, 15 and 14, rejects 13, keeps 12 and rejects 11. We call the sources it keeps U*, and here they sum to 135. An optimal game of 21 plays all of them and one factor more, 9, for 144.

Layers 1 and 2

The bottom-layers theoremTheorem F4proved, proof on GitHub

In layers 1 and 2, every optimal game plays exactly the sources that descending greedy keeps.

Precisely.Let S be an optimal set of n. Then S plays q(n), the largest prime up to n, and no other prime; its sources in layer 2 are exactly U*2, the members of U* in layer 2; and its members in layer 2 form a forest in the graph on the primes, on which descending greedy is the greedy algorithm.

In the two bottom layers, descending greedy is provably right. Layer 1 holds the primes, and every prime above n/2 needs the same factor, 1, to pay for it. Greedy keeps the largest and rejects the rest, which is what every optimal game does, by chapter 2's prime lemma.

Layer 2 as a graph

The graph joins each number of layer 2 to its prime factors: pq to p and q, and p² to p and to one more vertex, g. The primes can pay for a set of such numbers exactly when, with the primes and g, it forms a forest, a graph with no loop (the loop rule). Game 100 has no square among its sources, since 7² = 49 is below 50 and 11² = 121 above 100.

The square theoremTheorem F10proved, proof on GitHub

From game 187 on, the sources greedy keeps in layer 2 need every prime up to n/2, so an optimal game plays no other number with two prime factors.

Precisely.Greedy's layer-2 sources leave one prime to spare in each piece of the graph with no square among its sources, and none in a piece with one. From game 187 on, the graph is one piece with a square. The proof checks the boards of games 187 to 2,499, and primes in short intervals, by computation.

Layer 2 holds the numbers with two prime factors, and there chapter 1's loop does the work. Draw layer 2 as a graph, and a source such as 95 sits between its two maximal factors, the primes 5 and 19, as 10, 14, 15 and 21 sat on the sides of a square on 2, 5, 3 and 7. Numbers like these are playable together exactly when they and their primes make no loop. So greedy keeps a source of layer 2 exactly when it closes no loop with the ones it kept. Here it is on game 100, whose 17 sources with two prime factors lie on the 15 primes up to 50.

Greedy keeps 14 of the 17. It refuses 58, 55 and 51, and each would close a loop of four, chapter 1's loop again. What it keeps joins all 15 primes with no loop: a tree. Taking the sources from the heaviest down and refusing any that closes a loop builds the heaviest tree: it is Kruskal's algorithm, and here it settles the game: every optimal game plays exactly the sources of layer 2 that greedy keeps.

Game 100's tree holds 14 sources, so it needs 14 of the 15 primes to pay for them, and one is to spare. From game 187 on, no prime ever remains to spare: the sources greedy keeps in layer 2 need every prime up to n/2, so no other number of layer 2 is playable, and that settles layer 2 completely.

Above layer 2

From layer 3 up, a number can have more than two maximal factors: 30 has three, 15, 10 and 6. With three, a loop no longer means that its numbers are stuck: 12, 20 and 30 make one, and the player can play all three (chapter 1). The reason greedy is safe in layer 2 is gone.

Where exchange breaksproved, proof on GitHub

Six sources of game 2,873 have sets that can take no more of them at two sizes, four and five.

Precisely.Y = {1573, 2057, 2431, 2873} and Y′ = {1573, 1859, 2057, 2197, 2873} are both playable, and no member of Y′ fits into Y: the playable subsets of the six lack the exchange property. A computation proves that exactly 48 orders trap descending greedy, and the figure repeats it.

Here is why greedy is safe in layer 2: there, a playable set of sources with no room for another is a forest on the primes, and every such forest holds the same number of sources. So once nothing more fits, greedy has as many sources as any playable set can have: it is never stuck with too few.

With more than two maximal factors, that can fail, and game 2,873 shows it with six of its sources, whose only prime factors are 11, 13 and 17. In some orders, greedy keeps four of them, and then neither of the other two fits, though five of the six are playable together. In other orders, it keeps five. We know of no smaller game where greedy can be stuck like this.

Of the 720 orders of the six, 48 trap greedy at four: those that put 1859 and 2197 last. Descending greedy takes them from the largest down, which is not one of those orders, and keeps the heaviest five. So the order of the numbers protects it, even here.

The sources conjectureConjecture S1open, proved to game 100,000, evidence on GitHub

No playable set of sources outweighs U*.

Precisely.Every playable set S of sources of game n has ΣS ≤ ΣU*. A check of the span conjecture by the prover proves it in games 2 to 100,000 (the span theorem; the prover's record).

We have never caught descending greedy producing a suboptimal set of choices. In every game up to 100,000, a computation proves that no playable set of sources outweighs U*. It is linear algebra: for each source that greedy rejects, the computation shows its list of maximal factors to be a sum of the lists of sources it kept above it, in the arithmetic where 1 + 1 = 0.

Statement U

The uniqueness theoremTheorem Q1proved, proof on GitHub

Wherever no playable set of sources has more members than U* above any threshold, U* is the only heaviest playable set of sources.

Precisely.If every playable set S of sources has |S ∩ [t, n]| ≤ |U* ∩ [t, n]| for every t, then U* is the only heaviest playable set of sources, for every weighting that increases with value. The check of the span conjecture, the computation above, proves the condition wherever it passes.

So wherever that computation succeeds, as it does in every game up to 100,000, U* is the heaviest set of sources, and the only one. That does not yet make it the top half of an optimal game. A game that gives up a source frees the factor that paid for it, and the player can then play that factor as a move itself. An optimal game might, for all we can prove, play a lighter set of sources and win the points back below n/2.

Statement Uopen, proved to game 2,530, evidence on GitHub

Some optimal game plays every source that descending greedy keeps.

Precisely.U at n: some optimal set of n contains U*≥3, the members of U* in layers 3 and up (the statement). It holds wherever the prover's opt(n) is the score of a game that plays U*, every game up to 2,530 (what supports the scores).

Statement U says it never has to. It says that in every game, some optimal set of moves plays every source that descending greedy keeps. In layers 1 and 2 we have proved it, so statement U is about the sources with three or more prime factors. While we have evidence in support of statement U, we do not have proof it always holds.

A second program, the prover, has found the best score on the whole board for every game up to 2,530, without assuming statement U, and in each of those games some optimal game plays all of U*. Game 2,531 follows from game 2,530 by the prime formula, and from game 2,532 on, our scores rest on statement U: each is the best score of a game that plays U*, and that is the best possible score assuming it holds.
