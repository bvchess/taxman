Chapter 3

The top half

The numbers above n/2 carry most of the score: about 93% of it in the games that need a search. One greedy pass chooses them.

Sources

Layers, precisely

The layer of x is Ω(x), its prime factors counted with multiplicity: Ω(12) = Ω(2 · 2 · 3) = 3, and Ω(1) = 0. A maximal factor x/p has the layer Ω(x) − 1, so every line of the maximal-factor graph joins two neighboring layers.

Start from the pot of game 21, and set its numbers out as chapter 1's graph does, in columns by layer. A number's layer is its count of prime factors, with repeats: 12 = 2 · 2 · 3 is in layer 3, every prime is in layer 1, and 1 alone is in layer 0. A number's maximal factors lie one layer down, so every line runs one column to the right.

Sources, precisely

The sources of game n are the s with n/2 < s ≤ n. Since 2s > n, no multiple of s but s itself is on the board, so s is never tax. The factors are 1 to ⌊n/2⌋.

Now cut every column at n/2. A number above n/2 divides no other number on the board, since twice it is already more than n. So the taxman can never take it as tax: it is a move or nothing. We call the numbers above n/2 the sources, and the numbers up to n/2 the factors. In game 21 the sources are 11 to 21, below the line.

The top half's sharemeasured, evidence on GitHub

Precisely.Over the 1,618 games whose recorded search explored nodes, in_the_bag / score runs from 91.9% to 97.1%, and from 92.1% to 93.2% past game 500. The recorded game plays exactly U* above n/2, so in_the_bag, the sum of U*, is what its sources score.

The sources are the larger half of the numbers, so they are where most of the points are. In the games of the chain that needed a search, the sources the optimal game plays carry about 93% of its score.

Descending greedy

Which sources should a game play? It cannot always play them all. In game 21 the primes 11, 13, 17 and 19 each have one maximal factor, 1, and two moves cannot share a payment, so at most one of the four can be played.

Descending greedy, precisely

It takes the sources in decreasing order and keeps each one that, with the sources kept so far, is playable, which peel decides (the theory). The frame solver runs it as part of its setup (setup in the code).

Descending greedy chooses the sources in one pass. It takes them from the largest down and keeps each one that can still be played together with those it kept before. In game 21 it keeps 21, 20, 19 and 18, then rejects 17, since 1 already pays for 19. It keeps 16, 15 and 14, rejects 13, keeps 12 and rejects 11. The sources it keeps are called U*, and here they sum to 135. Game 21’s optimal game plays all of them and one factor more, 9, for 144.

Layers 1 and 2

The bottom-layers theoremTheorem F4proved, proof on GitHub

In layers 1 and 2, every optimal game plays exactly the sources that descending greedy keeps.

Precisely.Let S be an optimal set of n. Then S plays q(n), the largest prime up to n, and no other prime; its sources in layer 2 are exactly U*2, the members of U* in layer 2; and its members in layer 2 form a forest in the graph on the primes, on which descending greedy is the greedy algorithm.

In the two bottom layers, descending greedy is provably right. Layer 1 holds the primes, and every prime above n/2 needs the same factor, 1, to pay for it. Greedy keeps the largest and rejects the rest, which is what every optimal game does, by chapter 2's prime lemma.

Layer 2 as a graph

The graph has a vertex for each prime up to n/2 and one more, g, and an edge for each number of layer 2: pq is the edge p–q, and p² the edge p–g. A set of such numbers can be paid for by the primes exactly when its edges form a forest, a graph with no loop (the loop rule). Game 100 has no square among its sources, since 7² = 49 is below 50 and 11² = 121 above 100.

The square theoremTheorem F10proved, proof on GitHub

From game 187 on, the sources greedy keeps in layer 2 need every prime up to n/2, so an optimal game plays no other number with two prime factors.

Precisely.Greedy's layer-2 sources leave one prime to spare in each piece of the graph with no square among its sources, and none in a piece with one. From game 187 on, the graph is one piece with a square. The proof checks the boards of games 187 to 2,499, and primes in short intervals, by computation.

Layer 2 holds the numbers with two prime factors, and there chapter 1's loop does the work. A source such as 95 = 5 · 19 is an edge between its two primes, as 10, 14, 15 and 21 were the edges of a square on 2, 5, 3 and 7. Numbers like these can all be played exactly when their edges contain no loop. So greedy keeps a source of layer 2 exactly when it closes no loop with the ones it kept. Here it is on game 100, whose 17 sources with two prime factors lie on the 15 primes up to 50.

Greedy keeps 14 of the 17. It refuses 58, 55 and 51, and each would close a loop of four, chapter 1's loop again. What it keeps joins all 15 primes with no loop: a tree. Taking the edges from the heaviest down and refusing any that closes a loop builds the heaviest tree, a classic fact, and here it settles the game: every optimal game plays exactly the sources of layer 2 that greedy keeps.

Game 100's tree has 14 edges, so it needs 14 of the 15 primes to pay for them, and one is to spare. From game 187 on, none ever is, and layer 2 is settled completely.

Above layer 2

From layer 3 up, a number can have three different prime factors, and then it has three maximal factors: 30 = 2 · 3 · 5 has 15, 10 and 6. It is no longer an edge between two numbers, and the reason greedy is safe in layer 2 is gone.

Where exchange breaksproved, proof on GitHub

Six sources of game 2,873 have sets that can take no more of them at two sizes, four and five.

Precisely.Y = {1573, 2057, 2431, 2873} and Y′ = {1573, 1859, 2057, 2197, 2873} are both playable, and no member of Y′ fits into Y: the playable subsets of the six lack the exchange property. That exactly 48 orders trap descending greedy is proved by computation, which the figure repeats.

That reason is simple. In layer 2, all the sets of sources that can be played and can take no more have the same size, as all the trees on the same primes have the same number of edges. So greedy is never stuck with too few. With three maximal factors this can fail, and in game 2,873 it does: six of its sources, built from the primes 11, 13 and 17, can be stuck at four, though five fit. Taken in some orders, greedy keeps four of them and then can fit no more. Taken in others, it keeps five. No smaller game is known where greedy can be stuck like this.

Of the 720 orders of the six, 48 trap greedy at four: those that put 1859 and 2197 last. Descending greedy takes them from the largest down, which is not one of those orders, and keeps the heaviest five. So the order of the numbers protects it, even here.

The sources conjectureConjecture S1open, proved to game 100,000, evidence on GitHub

No set of sources that can be played outweighs U*.

Precisely.Every playable set S of sources of game n has ΣS ≤ ΣU*. A check of the span conjecture (♦) by the prover proves it in games 2 to 100,000 (the span theorem; the prover's record).

Greedy has never been caught. In every game up to 100,000, a computation certifies that no set of sources that can be played outweighs U*. It is linear algebra: for each source that greedy rejects, its list of maximal factors is shown to be a sum of the lists of sources it kept above it, in the arithmetic where 1 + 1 = 0.

Statement U

The uniqueness theoremTheorem Q1proved, proof on GitHub

Wherever the cardinality conjecture (★) holds, U* is the only heaviest set of sources that can be played.

Precisely.Given (★), every playable set S of sources has |S ∩ [t, n]| ≤ |U* ∩ [t, n]| for every t. The check of (♦) proves (★) wherever it passes.

So wherever the certificate holds, U* is the heaviest set of sources, and the only one. That does not yet make it the top half of an optimal game. A game that gives up a source frees the factor that paid for it, and that factor can then be played as a move itself. An optimal game might, for all we can prove, play a lighter set of sources and win the points back below n/2.

Statement Uopen, proved to game 2,175, evidence on GitHub

Some optimal game plays every source that descending greedy keeps.

Precisely.U at n: some optimal set of n contains U*≥3, the members of U* in layers 3 and up (the statement). It holds wherever the prover's opt(n) is the score of a game that plays U*, every game up to 2,175 (what supports the scores).

Statement U says it never has to. It says that in every game, some optimal game plays every source that descending greedy keeps. In layers 1 and 2 that is proved, so U is a statement about the sources with three or more prime factors. It is open in general.

It is proven in every game up to 2,175. There a second program, the prover, proves the best score on the whole board without assuming U, and the best score is that of a game that plays all of U*. Past game 2,175 our scores rest on U: each is the best score of a game that plays U*, and that is the best score of the game wherever U holds.
