Chapter 2

Walking up the chain

Game n is often easy if you know an optimal game of n − 1. So we play them in order, from game 1 up, and this way most games need no search at all.

MonotonicityLemma N3proved, proof on GitHub

The moves of any game of n − 1 are also a legal way to play game n, though never an optimal one: the best score always rises.

Precisely.Let n ≥ 2. The moves of a legal game of n − 1, in their order, are a legal game of n, with the same taxes, and the moves of a game of n that does not play n are a legal game of n − 1. Playing n in a game of n − 1, just before the move after which no maximal factor of n is left in the pot, and leaving that move out if it can no longer be played, gives a game of n that scores more. So opt(n − 1) < opt(n), every optimal game of n plays n, and a set without n is playable in game n exactly when it is playable in game n − 1.

Game n has the numbers of game n − 1 and one more, n. The new number divides nothing else on the board, so it is never tax. The moves of any game of n − 1 can therefore be played, in the same order, in game n, with every move taking the same tax as before. So the best score cannot fall: opt(n) is at least opt(n − 1).

In fact the best score always rises from one game to the next. In a game of n − 1 played in game n, n can be played as long as one of its maximal factors is still in the pot. So play n just before the move that takes the last of them from the pot, or at the end if one is left, and leave that move out if it can no longer be played. Everything after it stays legal, and the game gains n and loses at most that move, which is smaller than n. So the moves of a game of n − 1 are never an optimal game of n, and every optimal game of n plays n.

Take n = 12. Game 11's best score is 44, and its optimal game, played in game 12, takes the same tax with every move and leaves 12 in the pot. The maximal factors of 12 are 4 and 6. In that game, 6 is a move and 4 is taken by the last move, 8, so by the end both are gone, and 12 cannot simply come last. It is played just before 8 instead, and takes 4 itself. Then nothing is left to pay for 8, whose only maximal factor is 4, so 8 is left out, and the new game scores 44 + 12 − 8 = 48.

The ceiling lemmaLemma N4proved, proof on GitHub

Leave the move n out of a game of n, and the moves left are a legal game of n − 1, so the best score rises by at most n.

Precisely.Let n ≥ 2. The moves of a game of n other than n, in their order, are a legal game of n − 1. So opt(n) ≤ opt(n − 1) + n, the ceiling of game n, and if S is playable in game n, then S without n is playable in game n − 1.

An optimal game of n − 1 thus gives game n a lower bound, the score of the game built from it. It gives an upper bound too, since the best score never rises by more than n. Take an optimal game of n and leave out its move n. Everything n would have taken stays in the pot, so every other move still has tax to take, and what is left is a game of n − 1. It scores opt(n) − n, which is at most opt(n − 1).

An optimal game of 12 scores 50, and its move 12 takes 6. Without 12, 6 stays in the pot, and what is left is a game of 11 that scores 50 − 12 = 38, below game 11's best score of 44.

So opt(n − 1) + n is the most that any game of n can score. It is the ceiling of game n, and a game that reaches it is optimal, with nothing more to check. Put together, an optimal game of n − 1 bounds game n from both sides: opt(n − 1) < opt(n) ≤ opt(n − 1) + n. For n = 12:

opt(11)=44 game 11's best score opt(12)≥44 + 12 − 8 = 48 12 before 8, and 8 left out opt(12)≤opt(11) + 12 = 44 + 12 = 56 game 12's ceiling

Each game's best score bounds the next one's, so the games, from game 1 up, hang together like the links of a chain. In the figure, each game's link runs from its floor, opt(n − 1), up to its ceiling, opt(n − 1) + n, and its dot is opt(n), the start of the next link. A dot at the top of its link is a game at its ceiling, settled by game n − 1 alone.

When n fits

The step theoremTheorem N6proved, proof on GitHub

Game n is at its ceiling exactly when some optimal set of n − 1 can still be played with n added, and its optimal sets are then exactly those sets with n.

Precisely.Let n ≥ 2. Game n is at its ceiling iff some optimal set T of game n − 1 has T ∪ {n} playable in game n, and the optimal sets of game n are then exactly these sets T ∪ {n}.

The quickest way to a good game of n is to take an optimal set of game n − 1 and add n. If the set can still be played, it scores opt(n − 1) + n, the ceiling, and game n is done. We say that n fits into that optimal set.

Game 9's optimal set scores 30, and 10 fits into it. The maximal factors of 10 are 2 and 5, and its half, 5, divides nothing else up to 9, so it is never tax, and game 9's optimal set does not hold it. So an optimal game of 9 leaves 5 in the pot at the end, and 10 can follow it, paid for by 5. Game 10's best score is 30 + 10 = 40, its ceiling.

The half lemmaLemma N7proved, proof on GitHub

At an even n, if an optimal game of n − 1 leaves n/2 alone, game n is at its ceiling.

Precisely.Let n ≥ 4 be even. The number n/2 divides no number of the board of n − 1 but itself, so if some optimal game of n − 1 does not play n/2, it is still in the pot at the end, n can follow, and opt(n) = opt(n − 1) + n. For n twice a prime, an optimal game of n − 1 plays only its largest prime, which exceeds n/2 by Bertrand's postulate, so game n is always at its ceiling.

The same holds at every even n whose half an optimal game of n − 1 leaves alone.

Along the way: games 4, 6, 10, 14, 22, …When n is twice a prime OpenClose

When n is twice a prime p, n always fits. An optimal game of n − 1 plays only one prime, the largest on its board, and that prime is never p, since some prime always lies between p and 2p. So p is left alone, and since it divides nothing else up to n − 1, it is still in the pot at the end. Then n can follow, paid for by p.

Game 14 is one. An optimal game of 13 opens with 13 and leaves 7 in the pot, and 14 follows, paid for by 7: game 14 scores 52 + 14 = 66, its ceiling.

That a prime always lies between m and 2m, for every m from 2 up, is Bertrand's postulate. Joseph Bertrand guessed it in 1845 and checked it for every m below three million, and Pafnuty Chebyshev proved it a few years later. In 1931 Paul Erdős, then eighteen, found a much simpler proof, which became his first paper.

One optimal set

The step theorem asks about every optimal set of n − 1. Every game up to 424 has only one, which the prover finds by listing them all (measured); game 425 has two. So in these games one test decides whether n fits.

Game 11 has only one optimal set, and 12 does not fit into it. With 12 added, the set holds 8 and 12, and only 4 can pay for either: 12's other maximal factor, 6, is in the set, and 4 is the only maximal factor of 8. Each number of a playable set is paid for by a maximal factor of its own, so this set cannot be played, and game 12 falls short of its ceiling. An optimal game of 12 gives up 6, which then pays for 12, and scores 44 + 12 − 6 = 50.

At a prime

The prime lemmaLemma N1proved, proof on GitHub

Every optimal game opens with the largest prime of its board, and plays no other prime.

Precisely.Let n ≥ 2, and q(n) the largest prime up to n. Every optimal game of n plays q(n), as its first move, and no other prime: a game without it can take q(n) in place of its first move, or in front of it, and score more.

Past game 2, when n is a prime, it never fits, but an optimal game of n is still easy to find: take an optimal game of n − 1 and let n take the place of its first move, the largest prime below n.

A prime's only maximal factor is 1, and the first move of every game takes 1 as tax, so a prime can be played only as the first move. Every optimal game opens with the largest prime of its board: a game that does not can always play that prime in place of its first move, or in front of it, and score more. So an optimal set of n − 1 already holds a prime, and n, a second one, does not fit.

The prime formulaLemma N5proved, proof on GitHub

At a prime p, the largest prime below p gives way to p, and the score rises by their difference.

Precisely.Let p ≥ 3 be prime. Exchanging the opening move q(p − 1) for p turns a finished game of p − 1 into a finished game of p, and back, so opt(p) = opt(p − 1) + p − q(p − 1). The exchange maps the optimal sets of p − 1 one to one onto those of p (the step theorem).

The swap works because neither prime divides any other number on the board: the rest of the game cannot tell them apart, and every other move stays legal. The score rises by the gap between the two primes. Run backward, the same exchange turns an optimal game of n into a game of n − 1, so no game of n can beat the swap. This is the prime formula.

An optimal game of 12 opens with 11. In game 13, 13 takes its place, and the best score is 50 + 13 − 11 = 52.

A repeat

The repeat lemmaLemma R6conditional, proof on GitHub

If game n poses the search problem of an earlier game, the earlier game's answer gives an optimal game of n.

Precisely.Let Π_n = Π_m, root problems of games n and m. Every promotion set L makes a game of n worth ΣU*(n) + ΣL, and, given statement U at n, a promotion set that makes an optimal game of m makes an optimal game of n. The first part does not need statement U. Every game up to 2,530 is also proven by the prover, without statement U.

Most games in which n neither fits nor is prime still need no search. Before the frame solver searches a game, rules settle most of it (chapter 3 and chapter 4), and what is left is the game's search problem: which few numbers up to n/2 to play as moves as well. Often n does not change that problem at all. Then game n is a repeat, and the earlier game's answer to the problem is game n's answer too. The solver looks for one as soon as the problem is set up, before it searches (chapter 5).

The semiprime formulaTheorem J3proved, proof on GitHub

At an odd n with two prime factors that closes a loop with the moves of an optimal game of n − 1, as every one from game 189 on does, n takes the place of one move with two prime factors, and the best score rises by the difference: no search, and no statement U.

Precisely.Let n be odd with two prime factors, closing a cycle with U*₂(n − 1), as every such n ≥ 189 does, and x the smallest other member of the cycle. Then opt(n) = opt(n − 1) + n − x, and exchanging x for n maps the optimal sets of n − 1 onto those of n. In game 39, x = 22.

Game 39 is one. It poses the search problem of game 38, and an optimal game of 39 is an optimal game of 38 with one exchange: 39 takes the place of 22. Game 39's best score is 486 + 39 − 22 = 503, 22 below its ceiling. Here a theorem proves the same exchange with no search at all. It needs an odd n with two prime factors, as 39 = 3 · 13 is, and from game 189 on it covers every one.

Along the way: games 2,512 to 2,519 OpenClose

Games 2,512 to 2,519 pose one and the same search problem. The search of game 2,512 explored 8.7 million nodes, and the next 7 games needed no search of their own: each is a repeat. No other search in the chain carries as many games.

The whole chain

How the chart counts

A game counts under the first rule that applies, in the order prime, ceiling, repeat, search. So the ceiling holds 1,136 games the chain records as repeats, since the ceiling proves them from game n − 1 alone. The searches include 5 small games with nothing to choose.

The same rules carry the chain to its end. Of its 5,060 games, 65.4% were proven with no search of their own: 32.4% at the ceiling, 13.4% by the prime formula and 19.7% as repeats. The other 34.6% needed a search.

What each rule rests on

The ceiling and the prime formula prove the chain's game of n optimal wherever its game of n − 1 is. A repeat rests on statement U at n too, and a search on the frame model, which is exact where statement U holds. Every game up to 2,530 is also proven by the prover, on the whole board, without statement U (what supports the scores).

Each game proven without a search of its own rests on an earlier game, most often game n − 1, so the chain has to find its games in order, from game 1 up: game 5,000 is reached by walking there.

Which games need a search

The cofactor rulemeasured, evidence on GitHub

Whether a game needs a search can usually be told from n and its largest prime factor.

Precisely.Let n ≥ 28, and m be n − 1, or n − 2 when n − 1 is prime. If no frame of layer 2 has a freedom in game n or in game m, as for every n ≥ 188, then game n has the root problem of game m if its cofactor is a prime or twice a prime, and is at its ceiling if its cofactor is 9. The first case is proved, by the layer-2 corollary (J2); the other two are measured.

Whether a game needs a search can usually be told from n alone, before any work. Write n as its largest prime factor times what is left, the cofactor of n: in game 3,002, n = 38 · 79 has the cofactor 38, and a prime has the cofactor 1. From game 188 on, no game whose cofactor is 1, a prime, twice a prime or 9 needed a search.

Those four cofactors take in 2,730 of the 4,873 games from game 188 on, and 86% of the ones settled with no search. Of the 2,143 games with any other cofactor, 1,691 needed a search.

A game that needs a search still gets help from game n − 1: its search starts near the best, and stops as soon as it reaches the ceiling (chapter 5).
