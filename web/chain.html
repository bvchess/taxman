Chapter 2

Walking up the chain

Game n is often easy if you have an optimal game n − 1. So we play them in order, from game 1 up, and this way most games need no search at all.

MonotonicityLemma N3proved, proof on GitHub

The moves of any game of n − 1 are also a legal way to play game n, though never an optimal one: the best score always rises.

Precisely.Let n ≥ 2. The moves of a legal game of n − 1, in their order, are a legal game of n, with the same taxes, and the moves of a game of n that does not play n are a legal game of n − 1. Playing n in a game of n − 1, just before the move after which no proper divisor of n is left in the pot, and leaving that move out if it can no longer be played, gives a game of n that scores more. So opt(n − 1) < opt(n), every optimal game of n plays n, and a set without n is playable in game n exactly when it is playable in game n − 1.

Game n has the numbers of game n − 1 and one more, n. The new number divides nothing else on the board, so it is never tax. The moves of any game of n − 1 can therefore be played, in the same order, in game n, with every move taking the same tax as before. So the best score cannot fall: opt(n) is at least opt(n − 1).

Take n = 12. Game 11's best score is 44, from the optimal game 11, 9, 6, 10, 8, whose moves take 1, 3, 2, 5 and 4 as tax. Played in game 12, the same moves take the same tax, and 12 stays in the pot.

In fact the best score always rises from one game to the next. In a game of n − 1, play n just before the move that takes the last divisor of n from the pot, or at the end if a divisor is left, and leave that move out if it can no longer be played. Everything after it stays legal, and the game gains n and loses at most that move, which is smaller than n. So the moves of a game of n − 1 are never an optimal game of n, and every optimal game of n plays n.

In game 12, the game above cannot simply end with 12, since by then 1, 2, 3, 4 and 6 are all gone. The last of them to go is 4, taken by the last move, 8. So 12 is played just before 8, and takes 4 itself. Then 8 has no divisor left and is left out, and 11, 9, 6, 10, 12 scores 44 + 12 − 8 = 48.

The ceiling lemmaLemma N4proved, proof on GitHub

Leave the move n out of a game of n, and the moves left are a legal game of n − 1, so the best score rises by at most n.

Precisely.Let n ≥ 2. The moves of a game of n other than n, in their order, are a legal game of n − 1. So opt(n) ≤ opt(n − 1) + n, the ceiling of game n, and if S is playable in game n, then S without n is playable in game n − 1.

Nor can it rise by more than n. Take an optimal game of n and leave out its move n. Everything n would have taken stays in the pot, so every other move still has its divisor, and what is left is a game of n − 1. It scores opt(n) − n, which is at most opt(n − 1).

An optimal game of 12 is 11, 9, 10, 8, 12, which scores 50. Without 12, it leaves 6 in the pot and is a game of 11, which scores 38, below game 11's best score of 44.

So opt(n − 1) + n is the most that any game of n can score. It is the ceiling of game n, and a game that reaches it is optimal, with nothing more to check. For n = 12:

opt(11)=44 game 11's best score opt(12)≤opt(11) + 12 = 44 + 12 = 56 game 12's ceiling opt(12)=50 game 12's best score, 6 below its ceiling

When n fits

The step theoremTheorem N6proved, proof on GitHub

Game n is at its ceiling exactly when some optimal set of n − 1 can still be played with n added, and its optimal sets are then exactly those sets with n.

Precisely.Let n ≥ 2. Game n is at its ceiling iff some optimal set T of game n − 1 has T ∪ {n} playable in game n, and the optimal sets of game n are then exactly these sets T ∪ {n}.

The quickest way to a good game of n is to take an optimal set of game n − 1 and add n. If the set can still be played, it scores opt(n − 1) + n, the ceiling, and game n is done. We say that n fits into that optimal set.

Game 9's optimal set, 6, 7, 8 and 9, scores 30, and 10 fits into it. Its half, 5, divides nothing else up to 9, so it is never tax, and game 9's optimal set does not hold it. So 7, 9, 6, 8, an optimal game of 9, leaves 5 in the pot at the end, and 10 can follow it, paid for by 5. Game 10's best score is 30 + 10 = 40, its ceiling.

The half lemmaLemma N7proved, proof on GitHub

At an even n, if an optimal game of n − 1 leaves n/2 alone, game n is at its ceiling.

Precisely.Let n ≥ 4 be even. The number n/2 divides no number of the board of n − 1 but itself, so if some optimal game of n − 1 does not play n/2, it is still in the pot at the end, n can follow, and opt(n) = opt(n − 1) + n. For n twice a prime, an optimal game of n − 1 plays only its largest prime, which exceeds n/2, so game n is always at its ceiling.

The same holds at every even n whose half an optimal game of n − 1 leaves alone. When n is twice a prime, it always does: an optimal game plays only one prime, the largest, so the smaller prime n/2 is still in the pot at the end.

One optimal set

The step theorem asks about every optimal set of n − 1. Every game up to 424 has only one, which the prover finds by listing them all (measured); game 425 has two. So in these games one test decides whether n fits.

Game 11 has only one optimal set, 6, 8, 9, 10 and 11, and 12 does not fit into it. With 12 added, the set holds 8 and 12, and only 4 can pay for either. The maximal factors of 12 are 4 and 6, and 6 is in the set; the only maximal factor of 8 is 4. Each number of a playable set is paid for by a maximal factor of its own, so this set cannot be played, and game 12 falls short of its ceiling. An optimal game of 12 gives up 6, which then pays for 12, and scores 44 + 12 − 6 = 50.

At a prime

The prime lemmaLemma N1proved, proof on GitHub

Every optimal game opens with the largest prime of its board, and plays no other prime.

Precisely.Let n ≥ 2, and q(n) the largest prime up to n. Every optimal game of n plays q(n), as its first move, and no other prime: a game without it can take q(n) in place of its first move, or in front of it, and score more.

Past game 2, a prime never fits. Its only divisor is 1, and the first move of every game takes 1 as tax, so a prime can be played only as the first move. Every optimal game opens with the largest prime of its board: a game that does not can always play that prime in place of its first move, or in front of it, and score more.

The prime formulaLemma N5proved, proof on GitHub

At a prime p, the largest prime below p gives way to p, and the score rises by their difference.

Precisely.Let p ≥ 3 be prime. Exchanging the opening move q(p − 1) for p turns a finished game of p − 1 into a finished game of p, and back, so opt(p) = opt(p − 1) + p − q(p − 1). The exchange maps the optimal sets of p − 1 one to one onto those of p (the step theorem).

So at a prime n, an optimal game of n − 1 opens with the largest prime below n, and n takes its place. Neither prime divides any other number on the board, so the rest of the game cannot tell them apart, and every other move stays legal. The score rises by the gap between the two primes. Run backward, the same exchange turns an optimal game of n into a game of n − 1, so no game of n can beat the swap. This is the prime formula.

An optimal game of 12 opens with 11. In game 13, 13 takes its place, and the best score is 50 + 13 − 11 = 52.

A repeat

The repeat lemmaLemma R6proved given U, proof on GitHub

If game n poses the search problem of an earlier game, the earlier game's answer gives an optimal game of n.

Precisely.Let Π_n = Π_m, root problems of games n and m. Every promotion set L makes a game of n worth ΣU*(n) + ΣL, and, given statement U at n, a promotion set that makes an optimal game of m makes an optimal game of n. The first part needs no U. Every game up to 2,175 is also proven by the prover, without U.

Most games in which n neither fits nor is prime still need no search. Before the frame solver searches a game, rules settle most of it, and what is left is the game's search problem: which few numbers up to n/2 to play as moves as well. Often n does not change that problem at all. Then game n is a repeat, and the earlier game's answer to the problem is game n's answer too.

The semiprime formulaTheorem J3proved, proof on GitHub

At an odd n with two prime factors that closes a loop with the moves of an optimal game of n − 1, as every one from game 189 on does, n takes the place of one move with two prime factors, and the best score rises by the difference: no search, and no statement U.

Precisely.Let n be odd with two prime factors, closing a cycle with U*₂(n − 1), as every such n ≥ 189 does, and x the smallest other member of the cycle. Then opt(n) = opt(n − 1) + n − x, and exchanging x for n maps the optimal sets of n − 1 onto those of n. In game 39, x = 22.

Game 39 = 3 · 13 is one. It poses the search problem of game 38, and an optimal game of 39 is an optimal game of 38 with one exchange: 39 takes the place of 22 = 2 · 11. Game 39's best score is 486 + 39 − 22 = 503, 22 below its ceiling. Here a theorem proves the same exchange with no search at all, and it covers every odd n with two prime factors from game 189 on.

The whole chain

How the chart counts

A game counts under the first rule that applies, in the order prime, ceiling, repeat, search. So the ceiling holds … games the chain records as repeats, since the ceiling proves them from game n − 1 alone. A game of the bounds store, which proves bounds apart from the chain, counts by the bound it cites: … by the ceiling or the prime formula, … as repeats and … by searches. The searches include … small games with nothing to choose.

The same rules carry the chain to its end. Of its … games, … were proven with no search of their own, or …: … at the ceiling, … by the prime formula and … as repeats.

What each rule rests on

The ceiling and the prime formula prove the chain's game of n optimal wherever its game of n − 1 is. A repeat rests on statement U at n too, and a search on the frame model, which is exact where U holds. Every game up to 2,175 is also proven by the prover, on the whole board, without U (what supports the scores).

That is why the result is a chain. For each of those games, the chain builds its optimal game from the one of game n − 1, so the games are found in order, from game 1 up: game 5,000 is reached by walking there.

Which games need a search

The cofactor rulemeasured, evidence on GitHub

Whether a game needs a search can usually be told from n and its largest prime factor.

Precisely.Let n ≥ 28, and m be n − 1, or n − 2 when n − 1 is prime. If no frame of layer 2 has a freedom in game n or in game m, as for every n ≥ 188, then game n has the root problem of game m if its cofactor is a prime or twice a prime, and is at its ceiling if its cofactor is 9. The first case is proved, by the layer-2 corollary (J2); the other two are measured.

Whether a game needs a search can usually be told from n alone, before any work. Write n as its largest prime factor times what is left, the cofactor of n: in game 3,002, n = 38 · 79 has the cofactor 38, and a prime has the cofactor 1. From game 188 on, no game whose cofactor is 1, a prime, twice a prime or 9 needed a search.

Those four cofactors take in … of the … games from game 188 on, and … of the ones settled with no search. Of the … games with any other cofactor, … needed a search.

A head start

The two starts of game 5,060

As sums of promotions, the part of the score a search chooses: the best is …, and the search starts at … from game 5,059’s optimal set and at … on its own. The frame solver measured both, each search stopped after its first thousand nodes (the start of game 5,060). What a start below the best costs a search was measured at game 3,020 (a start below opt(n)).

A game that needs a search still gets a start from the game before. The search of game n starts from the optimal set of game n − 1, carried over to game n, and that start is usually optimal or close to it. Game 5,060’s search starts … points below the best score this way; from a start of its own, it would begin … below. A search keeps only the branches that might beat the best game it has found, so the nearer it starts to the best, the less it has to search. A start far below the best can make a search many times longer.

Game n − 1 helps in two more ways. The ceiling it gives game n ends a search as soon as the search finds a game that reaches it: … searches of the chain ended there, … of them at their start, before a single step. And where game n poses part of the problem game n − 1 posed, the search can drop that part, by the near-repeat lemma (chapter 5).
