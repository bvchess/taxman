Chapter 2

Walking up the chain

Most games are easy if you know an optimal game of the one before. So we play them in order, from game 1 up, and most steps need no search at all.

MonotonicityLemma N3proved, proof on GitHub

A game of n − 1 is a game of n, so the best score never falls.

Precisely.Let n ≥ 2. A game of n − 1 is a game of n, with the same taxes, and a game of n that does not play n is a game of n − 1. So opt(n − 1) ≤ opt(n), and a set without n is playable in game n exactly when it is playable in game n − 1.

Game n has the numbers of game n − 1 and one more, n. The new number divides nothing else on the board, so it is never tax. A game of n − 1 is therefore still a legal game of n, with every move taking the same tax as before. So the best score never falls: opt(n) is at least opt(n − 1).

The ceiling lemmaLemma N4proved, proof on GitHub

Leave the move n out of a game of n, and a game of n − 1 is left, so the best score rises by at most n.

Precisely.Let n ≥ 2. The moves of a game of n other than n, in their order, are a game of n − 1. So opt(n) ≤ opt(n − 1) + n, the ceiling of game n, and if S is playable in game n, then S without n is playable in game n − 1.

Nor can it rise by more than n. Take an optimal game of n and leave out the move n. Everything n would have taken stays in the pot, so every other move still has its divisor, and what is left is a game of n − 1. It scores opt(n) − n, which is at most opt(n − 1).

So opt(n − 1) + n is the most that game n can score. It is the ceiling of game n, and a game that reaches it is optimal, with nothing more to check.

When n fits

The step theoremTheorem N6proved, proof on GitHub

Game n reaches its ceiling exactly when some optimal set of n − 1 can still be played with n added, and its optimal sets are then exactly those sets with n.

Precisely.Let n ≥ 2. Game n is at its ceiling iff some optimal set T of game n − 1 has T ∪ {n} playable in game n, and the optimal sets of game n are then exactly these sets T ∪ {n}.

The quickest way to a good game of n is to take an optimal set of game n − 1 and add n. If the set can still be played, it scores opt(n − 1) + n, the ceiling, and game n is done. We say that n fits.

Game 21's optimal set is 9, 12, 14, 15, 16, 18, 19, 20 and 21, and it scores 144. 22 fits. Its half, 11, divides nothing else up to 21, so it is never tax, and the game of 21 does not play it. So 11 is still in the pot at the end, and 22 can be played last, paid for by 11. Game 22 scores 144 + 22 = 166, its ceiling.

The half lemmaLemma N7proved, proof on GitHub

At an even n, if an optimal game of n − 1 leaves n/2 alone, game n is at its ceiling.

Precisely.Let n ≥ 4 be even. The number n/2 divides no number of the board of n − 1 but itself, so if some optimal game of n − 1 does not play n/2, it is still in the pot at the end, n can follow, and opt(n) = opt(n − 1) + n. For n twice a prime, an optimal game of n − 1 plays only its largest prime, which exceeds n/2, so game n is always at its ceiling.

The same holds at every even n whose half the game before leaves alone. When n is twice a prime, it always does: an optimal game plays only one prime, the largest, so the smaller prime n/2 is still in the pot at the end.

One optimal set

The step theorem asks about every optimal set of n − 1. Every game up to 424 has only one, which the prover finds by listing them all (measured); game 425 has two. So in these games one test decides whether n fits. The optimal sets of games 20 to 23 are also checked by an exhaustive search (the step theorem's examples).

21 does not fit. Game 20 has only one optimal set, 10, 12, 14, 15, 16, 18, 19 and 20. With 21 added it holds 10, 14, 15 and 21, the loop of chapter 1 on the primes 2, 5, 3 and 7, and no game plays all four. So game 21 cannot reach its ceiling of 124 + 21 = 145. Its optimal game gives up 10 and plays 9 instead, and scores 144.

At a prime

The prime lemmaLemma N1proved, proof on GitHub

Every optimal game opens with the largest prime of its board, and plays no other prime.

Precisely.Let n ≥ 2, and q(n) the largest prime up to n. Every optimal game of n plays q(n), as its first move, and no other prime: a game without it can take q(n) in place of its first move, or in front of it, and score more.

Past 2, a prime never fits. Its only divisor is 1, and the first move of every game takes 1 as tax, so a prime can be played only as the first move. Every optimal game opens with the largest prime of its board: a game that does not can always play that prime in place of its first move, or in front of it, and score more.

The prime formulaLemma N5proved, proof on GitHub

At a prime p, the largest prime below p gives way to p, and the score rises by their difference.

Precisely.Let p ≥ 3 be prime. Exchanging the opening move q(p − 1) for p turns a finished game of p − 1 into a finished game of p, and back, so opt(p) = opt(p − 1) + p − q(p − 1). The exchange maps the optimal sets of p − 1 one to one onto those of p (the step theorem).

So at a prime n, an optimal game of n − 1 opens with the largest prime below n, and n takes its place. Neither prime divides any other number on the board, so the rest of the game cannot tell them apart, and every other move stays legal. The score rises by the gap between the two primes. Run backward, the same exchange turns an optimal game of n into a game of n − 1, so no game of n can beat the swap. This is the prime formula.

Game 22 opens with 19. In game 23, 23 takes its place, and the game scores 166 + 23 − 19 = 170.

A repeat

The repeat lemmaLemma R6proved given U, proof on GitHub

If game n poses the search problem of an earlier game, the earlier game's answer gives an optimal game of n.

Precisely.Let Π_n = Π_m, root problems of games n and m. Every promotion set L makes a game of n worth ΣU*(n) + ΣL, and, given statement U at n, a promotion set that makes an optimal game of m makes an optimal game of n. The first part needs no U. Every game to 2175 is also proven by the prover, without U.

Most games that neither fit nor are prime still need no search. Before the frame solver searches a game, rules settle most of it, and what is left is the game's search problem: which few numbers up to n/2 to play as moves as well. Often n does not change that problem at all. Then game n is a repeat, and the earlier game's answer to the problem is game n's answer too.

The semiprime formulaTheorem J3proved, proof on GitHub

At an odd n with two prime factors that closes a loop with the moves of game n − 1, as every one from 189 on does, n takes the place of one move with two prime factors, and the score rises by the difference: no search, and no statement U.

Precisely.Let n be odd with two prime factors, closing a cycle with U*₂(n − 1), as every such n ≥ 189 does, and x the smallest other member of the cycle. Then opt(n) = opt(n − 1) + n − x, and exchanging x for n maps the optimal sets of n − 1 onto those of n. In game 39, x = 22.

Game 39 = 3 · 13 is one. It poses the search problem of game 38, and its optimal game is game 38's with one exchange: 39 takes the place of 22 = 2 · 11. It scores 486 + 39 − 22 = 503, 22 below its ceiling. Here a theorem proves the same exchange with no search at all, and it covers every odd n with two prime factors from 189 on.

The whole chain

How the chart counts

A game counts under the first rule that settles it, in the order prime, ceiling, repeat, and a game whose search ran counts as a search. So the ceiling holds … games the chain records as repeats and … from the bounds store, which proves upper bounds apart from the chain.

The same rules carry the chain to its end. Of its … games, … were settled with no search, or …: … at the ceiling, … by the prime formula and … as repeats.

What each rule rests on

The ceiling and the prime formula prove a game optimal wherever the game before it is optimal. A repeat rests on statement U at n too, and a search on the frame model, which is exact where U holds. Every game to 2175 is also proven by the prover, on the whole board, without U (what supports the scores).

That is why the result is a chain. Each of those games is built from the one before, so the games are found in order, from game 1 up: game 5000 is reached by walking there.

The cofactor rulemeasured, evidence on GitHub

Whether a game needs a search can usually be told from n and its largest prime factor.

Precisely.Let n ≥ 28, and m be n − 1, or n − 2 when n − 1 is prime. If no frame of layer 2 has a freedom in game n or in game m, as for every n ≥ 188, then game n has the root problem of game m if its cofactor is a prime or twice a prime, and is at its ceiling if its cofactor is 9. The first case is proved, by the layer-2 corollary (J2); the other two are measured.
