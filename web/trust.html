Chapter 6

Trust

Every score is checked, and every score says what it rests on.

The checks, in the code

The referee shares no code with the frame solver's number theory. The verifiers are taxman verify-results results/optimal.jsonl.gz and python3 solver/tools/check_results.py results/optimal.jsonl.gz; both pass the file (what each checks).

A game is easy to check and hard to prove. Before any game of the chain counts, a referee replays it: every move must be legal, no move may be left at the end, and the moves must add up to the score recorded. A game that passes is a real game, so the best score of its board is at least its score.

Two verifiers then replay the whole file, each on its own: the frame solver's, and a second one, in Python, that shares no code with it. They also check that the scores never fall from one game to the next and never rise by more than n, and they work out each game's proof again from its record, so that no edit by hand can change one.

A replay shows that a game can be played, not that it is the best. That takes a proof.

A second program

The prover

A branch and bound over sets of moves, bounded by the parity bound, that takes the recorded score as its target. It rests only on the theory's theorems and on elementary bounds, and its exact methods are tested against brute force (its README). Both programs read the chain through one gzip decoder, whose check of every byte makes a misread fail loudly rather than hand both the same wrong game. The proofs reach 2175, where the chain ended when they were made (the proofs).

Every proof of the frame solver rests, in the end, on the frame model, which gives the best score exactly where statement U holds. So a second program, the prover, proves the scores again without it. It shares no proof code with the frame solver. It searches the whole board, sets of moves rather than promotions, with no frames, and proves that no set that can be played beats the recorded score.

It proves every score of the chain up to 2,175. There each score is opt(n) with no assumption, and statement U holds as well, since the frame model's best is that score.

The parity bound

The parity boundTheorem W1proved, proof on GitHub

The heaviest set that passes the test bounds opt(n).

Precisely.A playable set is independent with its own coordinates over GF(2) (the independence lemma, P10), which is independence at both parities of the layer. So opt(n) is at most the heaviest set independent at both parities. Weighted matroid intersection finds it, and a weight split checks its value.

The prover's bound is the test of chapter 5, applied to the whole board. List, for each number of a set, its maximal factors outside the set. In a set that can be played, no group of numbers lists every factor an even number of times. So the heaviest set with no such group bounds opt(n). We call it the parity bound.

The two gapsmeasured, evidence on GitHub

The parity bound's gap above opt(n) is about a tenth of Franklín and Moniot's.

Precisely.130 points against 1,200 at n = 1000 to 1300. Theirs is the heaviest set with a payment scheme, a maximum-weight matching (what the paper proves).

Franklín and Moniot's paper gives a looser bound: the heaviest set whose numbers can each be given a maximal factor of their own, from outside the set, to pay with. Every set that passes the parity test passes theirs, and the parity bound comes far closer to opt(n): its gap is about a tenth of theirs.

Why one is stricter than the other shows in a count. A payment scheme gives each number of a set a maximal factor of its own, from outside the set, to pay with. Count the schemes that pay with the same factors. A set is allowed by Franklín and Moniot's bound when some choice of factors gets at least one scheme, and by the parity bound when some choice gets an odd number. It can be played exactly when some choice gets exactly one.

The counting theoremTheorem C2proved, proof on GitHub

A set has a payment scheme, passes the parity test, or can be played exactly when some set of factors gets at least one, an odd number, or exactly one of its schemes.

Precisely.With per(S, T) the number of schemes of S onto the factors T, the three conditions are per(S, T) ≥ 1, odd, or 1, for some T. The odd count is independence over GF(2), since a permanent is its determinant mod 2.

Two schemes on the same factors differ around a loop: the triangle's second scheme is its first turned once around. Whichever of 6, 10 and 15 is played first takes both of its primes as tax, and one of the other two is left with nothing to pay with. Swap 6 for 9 and the loop opens: one scheme, and the set plays, 9 first.

The first odd coreProposition C3proved, proof on GitHub

Below 45 every set that passes the parity test can be played.

Precisely.Every S ⊆ {2, …, 44} independent with its own coordinates over GF(2) is playable, so the parity bound is opt(n) for n ≤ 44, and {12, 18, 20, 30, 45} is an odd core.

An odd count is what the parity test cannot tell from one. The five numbers 12, 18, 20, 30 and 45 have three schemes, all paying with 4, 6, 9, 10 and 15. Three is odd, so they pass the test, yet they cannot all be played: every number has two or more factors to pay with and every factor two or more takers, so peel has no safe step. A set like this, which passes the test and cannot be played, is an odd core, and 45 is the smallest board with one.

Exact to 77measured, evidence on GitHub

The parity bound equals opt(n) for every n up to 77, and exceeds it at 78.

Precisely.The prover's run on 2 to 1300 records each bound, checked by its weight split: at 78 it is 1,992 against opt(78) = 1,991 (the evidence). U* with 28, 30, 36 and 39 passes the test at that weight; the nine numbers drawn are what peel leaves of it.

Along the way: games 1 to 77A bound that is exact OpenClose

Up to game 77 the parity bound is exactly opt(n): below 45 no board has an odd core, and from 45 to 77 none of them raises the bound.

At game 78 the bound first misses, by one point: 1,992 against opt(78) = 1,991. A set worth 1,992 that passes the test is the optimal game's set with 28 promoted in place of 27, and these nine of its numbers cannot all be played.

Each lists two or three of the nine factors, and every factor is listed twice or more, so peel has no safe step. Yet no group of the nine lists every factor an even number of times. It is an odd core, the first that raises the bound.

What supports the scores

The corollary of UCorollary X8proved, proof on GitHub

The frame model's best score is never above opt(n), and equals it exactly when U holds.

Precisely.ΣU* + P*(Πn) ≤ opt(n), with equality iff U holds at n.

Statement Uopen, proved to 2,175, evidence on GitHub

Some optimal game plays every number of U* with three or more prime factors.

Precisely.Some optimal set of n contains U*≥3. It holds at every game the prover proves (the evidence).

Every score up to 2,175 is opt(n), proved on the whole board by the prover.

Past 2,175 the scores rest on the frame solver alone, 2,885 of them. Each is the best score of the frame model, and that is opt(n) exactly when statement U holds at n: when some optimal game plays every number of U* with three or more prime factors. U is open in general, so each of those scores is opt(n) given U.

Proofs and assumptions

Each line of results/optimal.jsonl.gz has a proof and an assumes. What a game assumes is what its proof rests on beyond the frame model; the verifiers derive both again (proof kinds, assumptions; what supports the scores).

The figure shows what each kind of proof rests on. A game at the ceiling or by the prime formula rests on the game before it, and a repeat on the game it repeats. A search rests on the frame model of its own game. The 382 games from 3,984 to 4,783 meet an upper bound that an earlier run of the solver proved, so they rest on the frame model of the games that bound came from.

Each game's line in the file says this itself: it names its proof and lists what the proof assumes. A line that assumes nothing is proved within the frame model, given that the solver is right. The lines of those 382 games list statement U at each game their bound came from, their own game or others.

The evidence for U

The lower layers: every optimal set holds U*1 and U*2, by the bottom-layers theorem (F4). The sources: the sources conjecture (S1), proved in every game up to 100,000. The barred bounds: W2, and their counts by band in the upper part, game by game. A sketch of what a counterexample would need: where a proof stops.

What supports U past 2,175:

  • It holds at every game the prover reaches, up to 2,175.
  • It is proved for the numbers with one or two prime factors: every optimal set holds those of U*. U asks the same of the numbers with three or more.
  • Among the sources alone, U* is the heaviest set that can be played, in every game up to 100,000.
  • The prover's barred bounds show, number by number, that any game beating the recorded score would have to play most of the numbers U asks about: about 85% of them in the games 2,176 to 3,314, though never all of a game's.
