Statement U

One open statement stands between the frame model and the best score. It is proven in every game up to 2,530.

What the scores rest on

The corollary of statement UCorollary X8proved, proof on GitHub

The frame model's best score is never above opt(n), and equals it exactly when statement U holds.

Precisely.ΣU* + P*(Πn) ≤ opt(n), with equality iff statement U holds at n.

Statement Uopen, proved to game 2,530, evidence on GitHub

Some optimal game plays every number of U* with three or more prime factors.

Precisely.Some optimal set of n contains U*≥3. It holds at every game the prover proves (the evidence).

The search of chapter 5 proves the best score of the frame model: the best score of a game that plays every number of U*. That is opt(n) exactly when statement U holds: when some optimal game plays every number of U* with three or more prime factors. For the numbers with one or two it is proved (chapter 3). For the rest it is open. An optimal game might give one of them up, free the factor that paid for it, and win the points back below n/2.

A score at the ceiling or by the prime formula rests on the game before it. A search rests on the frame model of its own game, and so does a repeat, which takes the answer of the earlier game that posed the same search problem. Followed down, every score rests on the frame model of some game. Up to game 2,530 that gives opt(n), proven. Past it, the scores rest on statement U from game 2,532 on, 2,529 of them. Game 2,531 follows from game 2,530 by the prime formula, so its score is proven too.

Proving it game by game

The prover

A branch and bound over sets of moves, bounded by the parity bound, that takes the recorded score as its target. It rests only on the theory's theorems and on elementary bounds, and its exact methods are tested against brute force (its README). Its run of games 2 to 2,530 took 19 hours on a machine with 88 threads (the proofs).

Statement U can be settled one game at a time: find opt(n) without the frame model, and compare. A second program, the prover, does that. It searches the whole board, sets of moves rather than promotions, with no frames. Its bound is the parity bound of chapter 6. Wherever its opt(n) is the frame model's best score, statement U holds.

It has proven every game up to 2,530. In each one opt(n) is the score the frame solver found, so statement U holds there, and the score is opt(n) with no assumption.

The evidence past 2,530

The evidence for statement U

The lower layers: every optimal set holds U*1 and U*2, by the bottom-layers theorem (F4). The sources: the sources conjecture (S1), proved in every game up to 100,000. The barred bounds: W2, and their counts by band in the upper part, game by game.

What supports statement U past game 2,530:

  • It holds in every game the prover reaches, up to game 2,530.
  • It is proved for the numbers with one or two prime factors: every optimal set holds those of U*. Statement U asks the same of the numbers with three or more.
  • Among the sources alone, U* is the heaviest set that can be played, in every game up to 100,000.
  • The prover can leave out one number of U* at a time and bound what any game without it could score. For about 85% of the numbers statement U asks about, in games 2,531 to 3,440, that bound is below the recorded score, so a game that beats the score, if there is one, plays them. In no game does it reach all of them.
  • At the start of the search of every game measured, up to game 3,440, the heaviest set that the parity bound allows holds all of them.

Where a proof stops

Suppose an optimal game leaves out some numbers of U* with three or more prime factors, and let d be the largest. Adding d back would make the game heavier, so it must make it unplayable: d is caught in a set of numbers that cannot all be played. If giving up a smaller number frees d, the exchange beats the game, so no optimal game leaves d out. In layer 2 such an exchange always exists, which is how the numbers with two prime factors are proved. Above layer 2, d can be caught in an odd core (chapter 6), and there the argument stops (a sketch).
