Chapter 7

Statement U

The best scores past game 2,531 rest on one statement that we have not proven in general. Up to game 2,531 the prover proves it, one game at a time.

What the scores rest on

The corollary of statement UCorollary X8proved, proof on GitHub

The frame model's best score is never above opt(n), and equals it exactly when statement U holds.

Precisely.ΣU* + P*(Πn) ≤ opt(n), with equality iff statement U holds at n.

Statement Uopen, proved to game 2,531, evidence on GitHub

Some optimal game plays every number of U* with three or more prime factors.

Precisely.Some optimal set of n contains U*≥3. It holds at every game the prover proves (the evidence).

The search of chapter 5 finds the best score of the frame model, in which the player plays every number of U* and chooses only the promotions. That score is the score of a real game, so it is never above opt(n). It equals opt(n) exactly when there exists an optimal game that plays all of U*.

In chapter 3 we've shown that every optimal game plays all of the numbers of U* that have one or two prime factors. For those with three or more, it is an open question. Statement U says that some optimal game plays them all. If it failed for some value of n, every optimal game of n would give one of them up, free the factor that paid for it, and win the points back with moves below n/2.

A score at the ceiling or by the prime formula rests on the score of the game before it. A score found by a search rests on the frame model of its own game, and so does a repeat, which takes the answer of an earlier game that posed the same search problem. A search uses the game before only as a starting point and finds the frame model's best from any start, so it inherits no error from below. So, followed down, every score rests on statement U at one game: either its own (if a search or a repeat settled it), or else the nearest game below it that was settled by a search.

We've verified statement U holds up to game 2,531. Past it, the rest of the chain rests on statement U.

Proving it game by game

The prover

A branch and bound over sets of moves that uses the parity bound and takes the recorded score as its target. It rests only on the theory's theorems and on elementary bounds, and we test its exact methods against brute force (its README). Proving every game up to 2,531 took it 19 hours on a machine with 88 threads (the proofs).

We can prove statement U one game at a time: find opt(n) without the frame model, and compare it with the frame model's best score. If the two are equal, statement U holds in that game. A second program, the prover, does this. It searches the whole board, choosing sets of moves rather than promotions, with no frames, and using the parity bound of chapter 6.

The prover has proven every game up to 2,531. In each one, opt(n) is the score the frame solver found. So statement U holds in those games, and their scores rest on no open statement.

The evidence past 2,531

The evidence for statement U

The lower layers: every optimal set holds U*1 and U*2, by the bottom-layers theorem (F4). The sources: the sources conjecture (S1), which we have proven in every game up to 100,000. The bounds that leave out one number of U*: W2, and their counts by band in the upper part, game by game.

What supports statement U past game 2,531:

  • It holds in every game the prover reaches, up to game 2,531.
  • For the numbers of U* with one or two prime factors, the theory proves it: every optimal game plays that portion of U*.
  • Among the sources alone, U* is the heaviest playable set in every game we've examined (up to 100,000). In those games, giving up a number in U* never pays within the top half.
  • For each game that rests on a search, the prover has tested the numbers in U* with three or more prime factors one at a time. For each, it bounds the score of any optimal game that gives that number up. When the bound is at most the recorded score, giving the number up cannot beat the record. In the games from 2,532 to 5,060 that rest on a search, about 80% of the numbers pass this test, so a game that beats a recorded score would have to give up one of the numbers that doesn't pass the test.
  • The parity bound lets through more sets than the player can play, so the heaviest set it allows answers a looser question than the game. With layers 1 and 2 played as every optimal game plays them, that heaviest set found by the parity bound keeps every number in U* in every game of the chain that rests on a search.

Where a proof stops

Why is statement U hard to prove? Suppose an optimal game leaves out some numbers of U* with three or more prime factors, and let d be the largest of them. Adding d would raise the score, so the game cannot play d as it stands: a knot of numbers in d's layer, a core, keeps d from being paid for. A proof would cut the knot with a trade that raises the score. The game could give up a smaller number of the knot and play d in its place, or give up a move below n/2, whose return to the pot pays for d. Either trade beats an optimal game, which is impossible, so a counterexample must block both. In layer 2 such a trade always exists, and that is how chapter 3 settles the numbers with two prime factors. Above layer 2, the knot can be an odd core (chapter 6), and no one has found a trade that is sure to cut one (a sketch).
