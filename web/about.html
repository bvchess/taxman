The theory

To our knowledge, these are original to this work:

  • The chain

    An optimal game for every game from game 1 to game n, each built from the one before, each with its proof and what that proof rests on. The prover, which shares no proof code with the frame solver, proves the scores to game 2,175 a second time, on the whole board (what supports the scores).

  • The frame model and its exactnessproved, proof on GitHub

    The frame model leaves only the promotions to choose, and the exactness theorem makes its best score the best score of a game that plays U*: opt(n) wherever statement U holds.

  • The peel theoremproved, proof on GitHub

    Peel decides whether a set of moves can be played, and never has to guess.

  • The bottom-layers theoremproved, proof on GitHub

    Every optimal game plays one prime, the largest, and among the numbers above n/2 with two prime factors exactly those that descending greedy keeps.

  • The parity bound and the counting theoremproved, proof on GitHub

    An upper bound on opt(n) from linear algebra over GF(2), and a count of payment schemes that places it between the sets that can be played and Franklín and Moniot’s bound (the counting theorem).

  • The findings along the way

    Two optimal sets at game 425, an optimal game one move short of the longest at game 833, and the others, a card each.

The game. Taxman is an educational computer game of the Minnesota Educational Computing Consortium, which published it in a collection of mathematics games and drills in 1983, as Hensley’s paper records.

The Taxman sequence. The best scores opt(1), opt(2), opt(3), … are the Taxman sequence, A019312 in the OEIS. The OEIS credits its earlier terms to Dan Hoey, up to game 158; Timothy Loh, up to game 227; Bernhard Esslinger, up to game 404; and van Nek, up to game 519. Its terms up to game 1,000 agree with the chain’s, one for one.

The share. Douglas Hensley proved in 1988 that the player’s share of the board tends to a constant, more than 1/2 and at most 35/48 (chapter 7). His strategy splits the board into blocks that are played in turn, each without disturbing the blocks after it.

Playability and hardness. Atli Fannar Franklín and Robert K. Moniot proved in 2023 that a set of moves can be played exactly when it is the set of upper ends of a matching of the maximal-factor graph with no flat alternating cycle: the playability theorem of chapter 1, in the language of matchings. They bounded opt(n) above by the heaviest matching of that graph, and proved NP-hard a more general game, played on any order of things in levels.

Heuristic strategies. A heuristic strategy plays a good game quickly, with no proof. Robert Moniot’s program plays seven, and the best of them, OneTax, wins 99.065% of the optimal points over games 2 to 1,000 (his strategies). The repository keeps the program as he sent it. Its source cites three earlier articles on the game: by L. A. Carmony and R. L. Holliday, 1993; by J. Trono, 1994; and by R. Moniot, 2007. The repository’s own strategies win 99.85% of the optimal points up to game 1,000, with no search (how they were measured).

How to cite the site

Cite the site by its author, title and address, and the code and the data by the repository:

Brian Chess. Taxman: Playing optimal games. https://vantuyl.com/taxman. Code and data: https://github.com/bvchess/taxman.

A score is best cited with the results file and its commit: the numbers of this site come from results/optimal.jsonl.gz at commit ….
