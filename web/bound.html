Chapter 6

The parity bound

A bound limits how high a score could possibly go. The more precise it is, the less a search has to explore. The parity bound provides a good combination of speed and precision.

The test

A search can stop exploring a branch as soon as it determines the branch cannot do better than the best game found so far (chapter 5). To decide that, it uses a bound, a number that no game in the branch can beat. A bound is never below the best the branch can reach, and the closer it comes to the true maximum, the more the search can skip.

Our bound uses a test inspired by the cycle trouble from chapter 1. Here's how it works: for each number of a set, list the maximal factors outside the set that could pay for it. If some of the numbers together list every factor an even number of times, the set is not playable. For example, 10, 14, 15 and 21 list each of 2, 3, 5 and 7 twice, so they cannot all be played together. Every playable set passes this test, though some sets that are not playable pass it too.

Even and odd

Give each number of a set a vector with a 1 for each maximal factor outside the set that it lists, and add the vectors in GF(2), the arithmetic of even and odd, where 1 + 1 = 0. A group of numbers that lists every factor an even number of times is a group whose vectors sum to zero. So a set passes the parity test exactly when its vectors are linearly independent over GF(2), which Gaussian elimination can check quickly.

We call this the parity test. It is quick to check, and a classical algorithm, weighted matroid intersection, finds the heaviest set of numbers that passes it. No playable set is heavier, so that set's sum is a bound, which we call the parity bound.

Some sets pass the test and still are not playable. Such a set contains an odd core, and odd cores are the only reason the bound ever exceeds the true maximum.

The whole board

The parity boundTheorem W1proved, proof on GitHub

The heaviest set that passes the test bounds opt(n).

A playable set passes the parity test (the independence lemma, P10), so opt(n) is at most the heaviest set that passes it. A number’s maximal factors lie one layer below it, so the test splits in two, one for the numbers of the odd layers and one for those of the even layers. Weighted matroid intersection finds the heaviest set that passes both, and a weight split checks its value.

Apply the parity bound to the numbers of the whole board, and it bounds opt(n) itself, since no playable set is heavier than the heaviest that passes the test.

The frame solver applies the same bound inside its search, at every node, to the promotions of each frame. At the root of a search, the parity bound of the frames limits what the promotions can add, and that limit plus the weight of U* is never above the parity bound of the whole board. On every board measured, from 2 to 8,191, the two are equal, so splitting the board into frames costs the bound nothing.

Odd cores

The first odd coreProposition C3proved, proof on GitHub

Below game 45 every set that passes the parity test is playable.

Every S ⊆ {2, …, 44} that passes the parity test is playable, so the parity bound is opt(n) for n ≤ 44. For n = 45, {12, 18, 20, 30, 45} is an odd core.

The five numbers 12, 18, 20, 30 and 45 pass the parity test, yet they are not playable, because peel, which decides whether a set is playable, cannot even begin. Every number has at least two factors to pay with, and every factor has at least two numbers that could use it, so peel has no safe first step. A set like this, which passes the test, is not playable, and contains no smaller such set, is an odd core. Game 45 is the first board with one.

What allows an odd core to exist? A number's maximal factors are the number divided by each of its primes, so a number with two different primes has two, and a number with three has three. The smallest with three is 30 = 2 · 3 · 5, with maximal factors 15, 10 and 6. Numbers that each have at most two maximal factors are playable exactly when they pass the parity test (the cycle rule of chapter 1), so a set of them is never an odd core, and every odd core contains at least one number with three or more maximal factors.

An odd core makes the bound miss only when no heaviest set that passes the test is playable. Up to game 77 that never happens, and the parity bound is equal to opt(n). Game 78 is the first where it misses.

Each of the nine numbers can pay with two or three of the nine factors, and each factor could pay for two or more of them, so again peel has no safe first step. Yet no group of the nine lists every factor an even number of times, so they pass the test. They are the first odd core that raises the bound past opt(n). Comparing bounds

Franklín and Moniot's paper gives a looser bound, the heaviest set whose numbers can each have a maximal factor of their own, from outside the set, to pay with. Every set that passes the parity test passes theirs, so their bound is never below the parity bound.

Each way of handing out factors is a payment scheme, and counting a set's schemes shows what each bound allows. Group the schemes by the factors they pay with, and count the schemes in each group. Franklín and Moniot's bound allows the set when some group has at least one scheme, and the parity bound allows it when some group has an odd number of schemes. The set is playable exactly when some group has a single scheme, which is Franklín and Moniot's playability theorem, their Theorem 1, in other words. In the figure, each set's schemes all pay with the same factors, so each set has one group.

The numbers 6, 10 and 15 have two schemes, so Franklín and Moniot's bound allows them. Two is even, so the parity bound does not, and it is right. Whichever of the three the player plays first takes both of its primes as tax, and that leaves one of the other two with nothing to pay with. The two schemes differ around a cycle. Turn the first once around the cycle, and you get the second. Swap 6 for 9 and there is no more cycle; there's only one scheme, and the set plays, 9 first.

The numbers 12, 18, 20, 30 and 45 have three schemes, an odd number, so both bounds allow them. Yet they are not playable. They are the first odd core.

The counting theoremTheorem C2proved, proof on GitHub

Group a set's schemes by the factors they pay with. The set has a scheme, passes the parity test, or is playable exactly when some group has at least one, an odd number, or a single scheme.

With per(S, T) the number of schemes of S onto the factors T, the three conditions are per(S, T) ≥ 1, odd, or 1, for some T. The odd count is independence over GF(2), since a permanent is its determinant mod 2.

Why would the parity test care how many schemes a set has? Make a table for one group of schemes, with a row for each number of the set and a column for each factor the group pays with, and write 1 where the number lists the factor and 0 elsewhere. A scheme picks a 1 in every row, no two in the same column, so the group's count is the number of such picks. The table's determinant, from linear algebra, adds up the same picks, each with a sign, plus or minus. Since +1 and −1 are both odd, the signs cannot change whether the total is even or odd, so the count and the determinant are both even or both odd.

A determinant is even if some of the table's rows add up to an even number in every column, and odd if no group of rows does. For the set, such rows are numbers that, together, list each of the group's factors an even number of times. In the table of 6, 10 and 15, all three rows add up to even in every column, and there are two picks. In the table of 9, 10 and 15, no group of rows does, and there is one. As linear algebra shows, a set passes the parity test exactly when some choice of columns makes its determinant odd. So the parity bound allows a set if and only if some group of its schemes has an odd count. This is the counting theorem.

Empirical results

How tight is the parity bound? Measured against opt(n), it settles out near 0.026% above opt(n), whereas Franklín and Moniot's bound hovers around 0.25% above opt(n), about 10 times higher.

For a search, the size of the gap is what matters. A branch survives as long as its bound beats the best game found, so the tighter the bound, the sooner the search can stop. We ran the prover's search on every game up to 1,000 twice, changing nothing but the bound. With Franklín and Moniot's bound, 294 games needed a search, and the searches explored 9.4 million nodes in all. With the parity bound, 241 games needed a search, and they explored only 67,000 nodes. The difference grows with n. Below game 500 the parity bound's searches are 16 times smaller, and from game 900 to 1,000 they are 168 times smaller.
