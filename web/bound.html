Chapter 6

The bound

A bound limits how high a score can go. The sharper it is, the less a search has to explore.

The test

The signed frame theoremTheorem B1proved, proof on GitHub

Promotions that can be made together pass the test in every frame.

Precisely.Give each move of a frame, and each number promoted into it, the vector of its maximal factors there, and each number promoted out of it its unit vector. A promotion set makes them linearly independent in every frame, over every field.

A search drops a branch when its bound cannot beat the best game found (chapter 5). The frame solver's bound is the heaviest set of candidates that passes a test: one that every set of legal promotions will pass, though some that cannot be made pass it too. It grows from the loop of chapter 1. List, for each number of a set, the maximal factors outside the set that could pay for it. If some of the numbers, taken together, list every factor an even number of times, the set cannot be played. The loop 10, 14, 15 and 21 lists each of 2, 3, 5 and 7 twice.

The frame boundCorollary B2proved, proof on GitHub

The heaviest set of candidates that passes the test in every frame bounds what a node can add.

Precisely.At a node with the promotions P and the candidates C, every completion P ∪ X has ΣX at most the heaviest ΣI, I ⊆ C independent in every frame together with P, within the node's promotion limit. The solver calls it the GF(2) bound. The only sets it lets through that cannot be promoted hold an odd core in some frame.

We call it the parity test: no group of a set's numbers may list every factor an even number of times. This is linear algebra over GF(2), the arithmetic of even and odd, so it is quick to check, and a classical algorithm, weighted matroid intersection, finds the heaviest set that passes it. That set's sum bounds what a branch can still add, so we call it the parity bound. The solver applies the bound to the promotions frame by frame, at every node.

Some sets pass the test and still cannot be played, and they are all that the bound misses: the odd cores.

The whole board

The parity boundTheorem W1proved, proof on GitHub

The heaviest set that passes the test bounds opt(n).

Precisely.A playable set is independent with its own coordinates over GF(2) (the independence lemma, P10), which is independence at both parities of the layer. So opt(n) is at most the heaviest set independent at both parities. Weighted matroid intersection finds it, and a weight split checks its value.

The parity bound needs no frames. Applied to the numbers of the whole board, rather than to the promotions of a frame, it bounds opt(n) itself: no set heavier than the heaviest that passes it can be played.

On every board from 2 to 8,191, splitting the board into frames costs the bound nothing. At the root of a search, the parity bound of the frames limits what the promotions can add, and that limit plus the weight of U* is exactly the parity bound of the whole board.

Comparing bounds

The two gapsmeasured, evidence on GitHub

The parity bound's gap above opt(n) is about a tenth of Franklín and Moniot's.

Precisely.130 points against 1,200 in games 1,000 to 1,300. Theirs is the heaviest set with a payment scheme, a maximum-weight matching (what the paper proves).

Franklín and Moniot's paper gives a looser bound: the heaviest set whose numbers can each be given a maximal factor of their own, from outside the set, to pay with. Every set that passes the parity test passes theirs, but the parity bound comes far closer to opt(n): its gap is about a tenth of theirs.

Each way of handing out those factors is a payment scheme, and counting a set's schemes shows what each bound allows. Group the schemes by the factors they pay with, and count each group. Franklín and Moniot's bound allows the set when some group has at least one scheme, and the parity bound when some group has an odd number. The set can be played exactly when some group has exactly one. In the figure, each set's schemes all pay with the same factors, so each set has one group.

The counting theoremTheorem C2proved, proof on GitHub

Group a set's schemes by the factors they pay with. The set has a scheme, passes the parity test, or can be played exactly when some group has at least one, an odd number, or exactly one scheme.

Precisely.With per(S, T) the number of schemes of S onto the factors T, the three conditions are per(S, T) ≥ 1, odd, or 1, for some T. The odd count is independence over GF(2), since a permanent is its determinant mod 2.

6, 10 and 15 have two schemes, so Franklín and Moniot's bound allows them. Two is even, so the parity bound does not, and it is right: whichever of the three is played first takes both of its primes as tax, and one of the other two is left with nothing to pay with. The two schemes differ around a loop: the second is the first turned once around. Swap 6 for 9 and the loop opens: one scheme, and the set plays, 9 first.

12, 18, 20, 30 and 45 have three schemes, an odd number, so both bounds allow them. Yet they cannot all be played: they are the first odd core.

Odd cores

The first odd coreProposition C3proved, proof on GitHub

Below game 45 every set that passes the parity test can be played.

Precisely.Every S ⊆ {2, …, 44} independent with its own coordinates over GF(2) is playable, so the parity bound is opt(n) for n ≤ 44, and {12, 18, 20, 30, 45} is an odd core.

The five numbers 12, 18, 20, 30 and 45 pass the parity test, yet they cannot all be played, because peel, which decides whether a set can be played, cannot even begin. Every number has at least two factors to pay with, and every factor at least two numbers that could use it, so peel has no safe first step. A set like this, which passes the test but cannot be played, is an odd core. Game 45 is the first board with one.

Exact to game 77measured, evidence on GitHub

The parity bound equals opt(n) for every game up to 77, and exceeds it at game 78.

Precisely.The prover's run on games 2 to 2,530 records each bound, checked by its weight split: at game 78 it is 1,992 against opt(78) = 1,991 (the evidence). U* with 28, 30, 36 and 39 passes the test at that weight; the nine numbers drawn are what peel leaves of it.

An odd core makes the bound miss only when no heaviest set that passes the test can be played. Up to game 77 that never happens, and the parity bound is exactly opt(n): below game 45 no board has an odd core, and in each of games 45 to 77 some heaviest set that passes the test can be played. Game 78 is the first where it happens, and the bound misses by one point: 1,992 against opt(78) = 1,991. Take an optimal set of game 78 and put 28 in place of 27. The set gains a point and still passes the test, but these nine of its numbers cannot all be played.

Each of the nine numbers can pay with two or three of the nine factors, and each factor could pay for two or more of them, so again peel has no safe first step. Yet no group of the nine lists every factor an even number of times, so they pass the test. They are the first odd core that raises the bound.
