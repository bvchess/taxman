# Evidence

Part of [the theory](../THEORY.md).

The computations behind the statements, each beside the statement it supports; the table of statements at the top gives
each one's standing.  No counterexample to (★) has been found anywhere.  The span certificate (♦) holds in every game to
100,000 and in 902 sampled games to 2,000,000: every rejection of greedy is a GF(2) dependency, which certifies (★) for
every component and truncation, and the upper-half conjecture for the game (Theorem 7).  Threshold by threshold, every
game to 20,000 is certified by bounds alone, with no search: one exclusion is always needed, the matching-number bound,
Lorea's hypergraphic-matroid bound, or the rank bound.  The rank bound also settles the five components that an earlier
campaign had left undecided (n = 3103, 3872, 3936, 4000 and 9170).  [solver/noframe/docs/star.md, "Conjecture (★) at
scale"](../../solver/noframe/docs/star.md#conjecture--at-scale) has the counts, the data, the programs and the
adversarial experiments.
